# Customer Service

`customer-service` manages business and individual customer profiles, KYC data, addresses, contacts, and status.

## Features
- Customer CRUD APIs
- Business and individual customer support
- Customer KYC and contact data
- JWT resource server integration
- Flyway migrations and PostgreSQL DB ownership

## Run
Use `mvn -pl customer-service spring-boot:run -Dspring.profiles.active=dev`
